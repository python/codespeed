About this site

We have nightly benchmark runs of PyPy, together with CPython data for comparison. The benchmarks ran from 2016-2026 on a dedicated machine named benchmarker. Previously, we had other machines (tannit and briefly speed-python). The benchmarker machine was generously donated by Baroque Software. Since mid-2026 the benchmarks are running on benchmarker2, which is a Hetzner AX41-NVMe machine donated by Hetzner. The specs are:

  • Processor: AMD Ryzen™ 5 3600 CPU with turbo disabled
  • RAM: 64GB Micron DDR4 MHz
  • Disk: two 512 GB NVMe SSDs in RAID 0
  • Benchmarking pinned with cpuset partitions to CPUs3,4,5 with SMT (hyper-threading) disabled, other machine operations are pinned to CPUs 1,2,3

About the benchmarks

The benchmark code can be found here.

This is a benchmark suite based on Unladen Swallow, adapted for PyPy and runs on Python2 and Python3.
Also see the speed.python.org site.
